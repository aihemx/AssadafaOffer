# Assadafa Exchange Offer

منشور تسويقي منظم لعروض الصرافة، مصمم ليكون قابلًا للمراجعة والتطوير والنشر عبر GitHub.

## الهدف

هذا المستودع يجمع محتوى منشور الصرافة، صفحة عرض بسيطة، وتوثيقًا يساعد الفريق على تعديل النصوص، مراجعة الرسالة التسويقية، وتجهيز النسخ للنشر على المنصات المختلفة.

## المحتويات

- `src/post.md`: نص المنشور العربي الجاهز للنشر.
- `src/index.html`: صفحة عرض بسيطة للمنشور.
- `src/styles.css`: تنسيق الصفحة.
- `docs/content-guide.md`: دليل تعديل المحتوى.
- `docs/social-publishing.md`: إرشادات النشر على السوشيال ميديا.
- `.github/ISSUE_TEMPLATE`: قوالب متابعة المهام والملاحظات.
- `.github/PULL_REQUEST_TEMPLATE`: قالب مراجعة التعديلات.

## معاينة محلية

افتح الملف التالي في المتصفح:

```text
src/index.html
```

لا يحتاج المشروع إلى تثبيت حزم أو تشغيل خادم.

## تخصيص سريع

عدّل القيم التالية داخل `src/post.md` و `src/index.html`:

- اسم الشركة أو المكتب.
- المدينة أو الفروع.
- أرقام التواصل.
- أسعار الصرف أو تفاصيل العرض.
- مدة العرض وشروطه.

## ملاحظات مهمة

أسعار الصرف تتغير باستمرار. يجب تحديث السعر والوقت والتاريخ قبل نشر أي منشور رسمي.
